Alignment to CIDOC CRM

  • Types: element designs and elements are crm:E99 Product Type; colours, categories, features and identifier systems are crm:E55 Type; units are crm:E58 Measurement Unit. An element is a narrower type of its design (P127) and carries its colour through P2 has type.
  • Things: a piece is a crm:E22 Human-Made Object typed by an element; assemblies and minifigures are E22 composed of pieces (P46).
  • CRMba: a build is a B1 Built Work, a layer a B2 Morphological Building Section (BP1 is section of).
  • CRMdig: a build model is a D1 Digital Object; a reconstruction is a D3 Formal Derivation using L21 and L22.
The alignment axioms were written by hand and have not been machine-checked against the published CRM RDFS files.
