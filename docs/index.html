Minimal Brick Ontology

A small OWL ontology and SKOS thesaurus for describing interlocking building bricks, plates, tiles and minifigure parts, and the models built from them. The ontology is aligned to CIDOC CRM (E22, E55, E58, E99), CRMba (B1, B2) and CRMdig (D1, D3); the catalogue follows DCAT-AP 3.0; the thesaurus and the build descriptions are validated with SHACL.

Independent community vocabulary. It is not affiliated with, authorised or endorsed by the LEGO Group. LEGO is a trademark of the LEGO Group. The LEGO Group publishes no open technical specification that we could retrieve, so every dimension is a nominal value from community sources, and every concept names the sources behind it.

What is verified

Each concept carries a verification status: sourced a retrieved source states it, seed author-supplied and not yet confirmed, rebrickable taken from the Rebrickable download. Hex values of the seed colours are approximations that are replaced when the Rebrickable colours file is processed (python main.py fetch).

Use it in a reconstruction workflow

A build is described by a small JSON spec (layers of pieces with part number, colour, stud position and rotation). The exporter checks part numbers, colours and overlaps and writes Turtle:

python py/mbo_build.py data/examples/pyramid_spec.json my-build.ttl

Parts and colours are referred to by their thesaurus slugs, for example part 3001 (Brick 2 x 4) in colour white. Grid units are studs (X, Y) and plate heights (Z); one brick layer is three plates high.
