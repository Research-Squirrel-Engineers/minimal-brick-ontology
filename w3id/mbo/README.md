# mbo

Persistent identifiers for the Minimal Brick Ontology (MBO): an OWL ontology, a SKOS
thesaurus, SHACL shapes and a DCAT-AP catalogue for building bricks.

* Namespace: `https://w3id.org/mbo/`
* Repository: https://github.com/Research-Squirrel-Engineers/minimal-brick-ontology
* Documentation: https://research-squirrel-engineers.github.io/minimal-brick-ontology/
